# PCMig 公司域环境验证清单

> 目的：在正式推广前，用两台公司测试机验证 PCMig 在域环境中的兼容性。
> 预期耗时：半天。需要 IT 配合：2 台测试机 + 1 个测试账号。

## 一、向 IT 申请的资源

| 资源 | 说明 |
|---|---|
| 旧测试机 | Win10 或 Win7，已加域，装有典型办公软件（Office/浏览器/ERP 客户端），放入测试用文件 |
| 新测试机 | Win11，已加域，标准镜像 |
| 测试账号 | 域管理员账号（首选）或两台机器的本地管理员 |
| 网络 | 两台机器互通即可（同 VLAN 即可，无需特殊配置） |
| 申请话术 | "验证一个内部迁移工具，只读旧机数据、写入新机，不改系统配置，全部操作有日志" |

## 二、域环境特有的验证项（虚拟机实验室覆盖不了的部分）

| # | 验证项 | 命令/操作 | 通过标准 | 被拦时的表现 |
|---|--------|-----------|---------|-------------|
| 1 | 域防火墙是否放行 SMB-In | `pcmig-cli preflight --host <旧机>` | "SMB 445 端口可达 ✔" | ✘ → 找 IT 加防火墙例外或确认文件共享 GPO |
| 2 | 域管理员凭据能否建立 IPC$ 会话 | 同上，带 `--user 域名\账号` | "IPC$ 凭据会话 ✔" | 错误 5/1326 → 换域管理员账号 |
| 3 | 管理共享是否可用（C$/D$） | 看 preflight 共享枚举结果 | 能列出 D$ 等 | 很多公司 GPO 会禁用管理共享 → 改用手工创建普通共享 |
| 4 | SMB 签名/加密强制策略 | 传输中观察 | 能正常传输即兼容 | 若报错，联系 IT 确认 SMB 策略级别 |
| 5 | UAC 远程令牌过滤 | 用本地管理员账号连旧机 | 连接成功 | Win7 上需内置 Administrator 或调 LocalAccountTokenFilterPolicy |
| 6 | EDR/DLP 是否拦截 robocopy 大批量读取 | 跑一次小批量 quick | 不被查杀/阻断 | 被查杀 → 找安全团队加白名单（我们的日志正好用于申诉） |
| 7 | Win7 源（如适用） | preflight Win7 测试机 | SMB2.1 协商成功 | 若公司强制 SMB3 加密，Win7 源需手工放通 |

## 三、端到端验收场景（与公司成功标准对齐）

1. **标准换机**：Win10 域机 → Win11 域机，D 盘数据全量迁移，L1 验证通过
2. **中断恢复**：传输中拔网线 10 分钟 → 恢复 → `resume` → 验证通过
3. **暂停上班**：下班开始迁移，上班前暂停，下班后恢复
4. **报告审计**：把 HTML 报告 + `logs\` 目录交给安全团队评审
5. **（可选）Win7→Win11**：验证数据优先模式的降级行为

## 四、给安全团队的说明要点

- 不持久化任何密码（凭据仅当次会话使用）
- 不迁移凭据/Cookie/证书（策略矩阵强制排除）
- 所有状态文件原子写入，Receipt 不可变，日志三份（应用/任务/robocopy）
- 传输通道即企业内网 SMB，与人工复制文件同等权限语义
- Job 数据落盘位置：`C:\ProgramData\PCMig\Jobs\`，可按保留策略清除
