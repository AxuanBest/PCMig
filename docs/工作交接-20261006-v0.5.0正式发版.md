## 6. 环境踩坑（**先读这节能省几个小时**）

1. **PS 5.1 + 无 BOM 的 UTF-8 = GBK 解码灾难**：中文（尤其**全角括号 `（）`**）会吞掉闭合引号 ⇒ `Missing ')' in method call`；中文**路径**会被毁（`docs\更新日志.md` → `docs\鏇存柊鏃ュ織.md`；`docs\测试报告-公司环境.md` → `docs\娴嬭瘯鎶ュ憡-鍏徃鐜.md` ⇒ `FileNotFoundException`）。⇒ 脚本尽量纯 ASCII；必须含中文就补 BOM（前三字节 `EF BB BF`），或把中文放独立 UTF-8 文本、由纯 ASCII 脚本用 `[Text.Encoding]::UTF8` **显式**读入拼接。
2. **`$Pid` / `$host` 是 PowerShell 只读自动变量**，用作函数参数名会报 `Cannot overwrite variable Pid because it is read-only or constant.` ⇒ 改名 `ProcessId`。
3. `[IO.File]::ReadAllText('相对路径')` 按**进程 CWD** 解析，**不随 `Set-Location` 变化** ⇒ 一律绝对路径。
4. 单命中 `(…).Count` 返回 `$null` ⇒ 用 `@(…).Count`。
5. `write` 工具产出的文件**无 BOM**；`edit` 可能顺手改掉 `.ps1` 的 BOM ⇒ 每次改完 `.ps1` 复查前三字节。
6. **断言不许命中自己的注释**：`src\PCMig.WinUI\PCMig.WinUI.csproj` 注释里写了 `src\PCMig.Gui\Assets\pcmig.ico`，命中 `tests\PCMig.Core.Tests\WinUiStep1ContractTests.cs` 的 `AssertNonePresent(csproj, …, "PCMig.Gui", "PCMig.Cli")` ⇒ 发版闸门 0/5 红。
7. `E:\PCMigLab\Staging\recovery-gate\launch-app.ps1` 的 **STALE-WARNING 是误报** —— 它把 `src\...\obj\` 里的构建中间产物也当"源文件"。真正的源文件最新时间早于 exe，构建是新的。
8. **本机窗口激活只认 `MinimizeAll()` + `UndoMinimizeAll()`**（`Shell.Application` COM）；`SetForegroundWindow` / `SetWindowPos(HWND_TOPMOST)` / `PrintWindow` 在本机都会拿到陈旧或错误的窗口。
9. 目标卷切换（VHD 挂载 / 卸载）**必须先关应用**，否则 WinUI 主进程会 `Responding=False` 并空转烧 CPU。
10. **★ bili 代理 0.1.184 的压缩缺陷 ★**：`acp_status` 报 `CONTEXT BREAKDOWN: 0 tool | 0 text | 0 summaries`、`max compressible 0`；0.1.185 的修复说明原文是「压缩会静默失效：后台小任务（如生成标题）抢走本会话『记忆锚点』，该会话从此无法压缩、上下文和 token 悄悄暴涨」（#2156 / #2160）。本会话所有 `compress` 调用都报 `startId="m00001" does not exist in this session` / `This conversation holds only 0 char(s)`。**唯一解：重启一次 dsh 升到 0.1.185。**
