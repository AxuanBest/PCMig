# PCMig 历史版本总索引（Legacy Versions Archive）

本索引对应 GitHub Release：**PCMig Legacy Versions Archive — Historical Installers (v0.1.0–v0.4.9)**

- 归档 tag：`legacy-installers-archive-20261006`（该 tag 只用于挂载这批历史安装包，**不是**任何版本的源码 tag）
- 原始开发与发布日期：2026 年 9 月（各版本日期见下表，取自当年的 `docs/更新日志.md` 版本对照表）
- GitHub 补传日期：2026-10-09（仅指本次上传时间，**不是**当年发布日期；当年并没有这些 GitHub Release）
- 归档内容：49 个原始安装包（v0.1.0–v0.4.9）+ 49 份逐版本更新日志 + 本索引 + 机器可核对的 SHA256 清单 + 日志打包 ZIP
- 这些安装包是当年真实构建的历史二进制，**本轮没有重新编译、没有改写旧源码、没有改动任何旧版本号**

> **这不是最新稳定版。** 推荐使用最新稳定版 **v0.5.3**（含失败证据可读、网速与剩余时间修正、提示卡与源连接状态修复）。
> 历史版本只代表它们发布时的状态，不保证适配现在的环境，也可能包含后来才修掉的问题。

## 四、证据级别与已知限制（如实说明）

- 安装包真实性：49 个安装包都在本机存在、**逐文件独立重算过 SHA256**，与 2026-10-06 留存的归档清单逐条一致；每个版本至少有 2 份互相独立的副本对账（证据等级 A）。
- 版本号元数据：全部 49 个安装包的 ProductVersion 与版本号一致；v0.2.0–v0.2.3 的 **FileVersion 当年写成 0.1.0.0**（历史遗留缺陷），本轮**原样保留，未修改任何旧 EXE**，也不因此改变其发布身份。
- 源码证据：只有 6 个版本有可核对的源码快照证据（v0.2.5 / v0.4.5 / v0.4.6 有精确快照；v0.4.7 / v0.4.8 / v0.4.9 有区间快照），**其余 43 个版本只有安装包（C 级证据）**。
- **不要把 GitHub 对归档 tag 自动生成的 『Source code』 压缩包当成历史源码**：那个 zip 是整个仓库某个提交的快照，不代表这些版本的源码。
- 验收证据：31 个版本能在《公司环境测试报告》里找到对应章节；其余版本没有当轮测试记录，本轮**没有也为它们编造测试结论**。
- 早期条目不确定：v0.1.0～v0.2.5 的条目来自当时的开发与实测记录，个别条目的版本归属可能存在 ±1 个版本的误差（当年日志已如此声明，本轮照实保留）。
- 未正式发布的编号：**v0.4.2 / v0.4.3 / v0.4.4 从未正式发布**，没有安装包，本归档**没有也不得补造**。
- 界面世代：v0.1.0–v0.4.9 全部是 **WPF 世代**（src/PCMig.Gui，
et8.0-windows，自包含 .NET 8）；v0.5.0 起才是 WinUI 3，因此不在本归档内。
- 兼容性：WPF 世代在 Windows 11 与 Windows 10 19041+ 上有当年的验证记录；更老的系统不受支持，本归档不改变这一点。
- 安全：49 个安装包的容器（Inno 引导程序与版本资源）已做内部信息扫描，未发现内部主机名、账号或口令等标记；但安装包内的程序载荷是压缩流，**无法用字节扫描证明其内部绝无历史内部字符串**，因此本归档不作此类保证。

## 五、怎么用这些历史包

1. 在 Release 的 Assets 里下载 `PCMigSetup-vX.Y.Z.exe`（安装包）与 `CHANGELOG-vX.Y.Z.txt`（该版本当年的完整更新日志）。
2. 用 `LEGACY-INSTALLERS-SHA256-20261009.txt` 逐条核对 SHA256（格式：`版本|文件名|字节数|SHA256|…`）。
3. 只想用工具做迁移的话，请直接下载最新的 **v0.5.3**，不要用历史版本。
