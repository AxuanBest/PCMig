# PCMig 历史版本发布索引（v0.1.0 → v0.4.9）

> **当前正式稳定版永远是 [v0.5.3](https://github.com/AxuanBest/PCMig/releases/tag/v0.5.3)。**
> 下面这些是**历史版本**，只作追溯与归档用途，**不要用于新的迁移任务**。

> 姊妹文档：`docs/历史版本索引.md` 讲「每个版本存在哪些证据、兼容性证据等级」；本文件讲「每个历史版本的 Release 在哪、怎么校验」。

## 这些历史 Release 是什么

- 每个历史版本一条独立 Release，标题为 `PCMig vX.Y.Z — Historical Binary Archive`，资产是**当年发布的原始安装包**与**该版完整更新日志**（另附 `SHA256SUMS-vX.Y.Z.txt`）。
- 每个 Release 使用的 Tag 是 `legacy-binary/vX.Y.Z`，语义是 **2026-10-09 的历史二进制验真锚点**，
  **它不是该版本当年的源码快照**；GitHub 在 Release 页自动附带的 `Source code (zip/tar.gz)` 是归档清单提交的内容，不代表历史源码。
- 历史安装包**未被重新编译**：PE 版本字段、签名与安装身份保持原样；v0.2.0–v0.2.3 的 `FileVersion` 落后为 `0.1.0.0` 属已知历史缺陷，未修改。
- 每个包的 SHA256 都在下面的表里；下载后可用 `Get-FileHash .\PCMigSetup-X.Y.Z.exe -Algorithm SHA256` 复算比对。

## UI 世代分界（便于按代浏览）

- `v0.2.3 → v0.2.4`、`v0.2.12 → v0.2.13`、`v0.2.29 → v0.3.1`、`v0.3.10 → v0.4.0`：WPF 世代内部的界面前后重做。
- `v0.4.1 → v0.4.5`：现代 UI 大重构（中间没有正式发布的 v0.4.2/v0.4.3/v0.4.4）。
- `v0.4.9 → v0.5.0`：WPF 世代结束，进入 WinUI 3 世代。
- 每个世代分界前最后一版（v0.2.3、v0.2.12、v0.2.29、v0.3.10、v0.4.1、v0.4.9）在表里标为「历史稳定基线」，语义是「重大 UI 变更前的最后一版」，**不等于通过稳定性认证**。

## 兼容与安全限制

- 历史版本可能包含后来已修复的问题（可靠性、数据安全、界面），本轮**没有**对它们重跑全量安全回归。
- 历史版本的数据路径、卸载身份与许可以随包内容为准；本次补归档不改动任何旧二进制。
- 若发现某个历史包与本地权威原件哈希不符，会在上面的表里标为 `BLOCKED`，不会提供下载。
