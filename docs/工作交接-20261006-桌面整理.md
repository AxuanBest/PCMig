## 七、纪律提醒（本轮再次验证）

1. **`.ps1` 必须 UTF-8 带 BOM**（`.md` 与 `docs\工作交接-*-QUICK.txt` 无 BOM；`.csv` 台账带 BOM 便于 Excel）。
2. **`edit` 命中 `PCMig\AGENTS.md` 会触发宿主重新注入整份文件（≈7.4–7.9K tokens）** —— 对该文件的多处修改务必合并成**一次**大段替换。
3. **`git status --porcelain` 不逐文件展开**（未跟踪目录被折叠）⇒ 逐文件计数必须加 **`-uall`**。
4. **`write` 生成的文件末尾无换行** ⇒ 之后用 `Add-Content` 会把新行粘到上一行行尾（本轮使 CSV 出现畸形行、`Import-Csv` 少 1 行）。追加前先补 `\r\n`，或用 `[IO.File]::AppendAllText`。
5. **删除守卫要按类型区分**：容器类（历史临时容器）必须为空才删；重复副本类允许非空。无差别守卫会误 ABORT。
6. `Move-Item -Destination` 结尾**带 `\` 表示移入该目录**，不带则视为改名目标。
7. 本机 `python`/`python3` 是 Microsoft Store 存根，用 `py -3`。
8. **权限放宽不构成豁免**；「不再弹窗」≠「已获用户同意」。视觉终验永远是用户人工。
