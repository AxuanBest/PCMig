## 三、本轮最重要的四条技术发现（下次不要再走弯路）

### 3.1 Composition 的"可动画属性"只有官方那一张表
`CompositionObject.StartAnimation` 的 Remarks 是唯一权威清单：**只有** `Visual` 的
AnchorPoint / CenterPoint / Offset / Opacity / Orientation / RotationAngle / RotationAxis / **Size** / TransformMatrix、
`InsetClip` 四边、`CompositionColorBrush.Color`、`CompositionPropertySet`、effect 参数。
- **没有** `Visual.Scale`，**没有任何** CompositionShape / CompositionGeometry 属性；
- `CompositionBrush.Opacity` **这个属性根本不存在**（写了 CS1061）；
- `CompositionSpriteShape` / `ShapeVisual` **都没有** `Shadow`（只有 `SpriteVisual` 有）；
- **`Compositor.CreateMatrix4x4KeyFrameAnimation` 不存在**。

⇒ 需要"几何 morph"时**不要硬凑关键帧**：本项目 U62 的做法是 **UI 线程按真实时间逐帧给已确认存在的属性赋值**
（`ShapeVisual.TransformMatrix` + `ColorBrush.Color` 的 alpha + `Visual.Opacity`），进度用 `Stopwatch` + `CompositionTarget.Rendering`。

### 3.2 `PointerEntered / PointerExited` 是 **Direct 路由**，祖先 `AddHandler` 收不到
上个会话留下的"指针移动事件没有到达这些卡片、根因未定位"就是这个。
按键类事件（`PointerPressed/Released`）与 **`PointerMoved`** 是冒泡的 ⇒ **hover 状态机必须由 `PointerMoved` 驱动**（取 `OriginalSource` 向上找宿主，仅在"当前悬停宿主变化"时切换）。

### 3.3 合成输入**驱动不了**指针移动 ⇒ Hover 无法自动验证
`SetCursorPos` 与 `mouse_event(MOVE|ABSOLUTE)` 注入的移动在 WinUI 3 里**不被指针管线处理**
（实测：不按按键时 `PointerMoved` 完全不触发；一旦发生按键，后续移动才开始有事件）。
⇒ 自动截图里 Hover 恒为 0 变化（`PrintWindow` 与 `CopyFromScreen` 都试过），**这是取证限制，不是实现失败**；
`Pressed` 路径可以用合成输入验证。Hover 的结论只能来自**真实鼠标 + 事件日志**。

### 3.4 诊断日志是本会话定位一切疑难问题的唯一可靠手段
统一做法：`env 开关 → 立即 return（零开销）→ 追加写 %TEMP%\pcmig-*.log`。本轮三次靠它破案：
- `PCMIG_FLUIDZOOM_DIAG` → 证明代次接管正确、`inherited=True`、旧代收尾被忽略，并抓出 source 漂移污染几何测量；
- `PCMIG_HOVER_DIAG` → 证明 `PointerEntered` 收不到、`PointerMoved` 能收到、位移精确为 −2.00 / −1.30；
- `PCMIG_RESPONSIVE_DIAG` → 记录每次布局决策的 `mode / client / design / viewport / p1..p4`，
  **"页面根 vs 页面视口"就是"是否被裁"的直接证据**（不必靠截图猜）。

## 四、工具坑（本轮新增，补进既有坑清单）

| # | 坑 | 规避 |
|---|---|---|
| 35 | **`Copy-Item -LiteralPath` 不支持通配符**（配 `-ErrorAction SilentlyContinue` 会静默漏文件 —— 曾漏掉 10 个 GIF + 10 个 CSV） | 通配符一律用 `-Path`；归档后必须逐项校验数量 |
| 36 | **同一位置两次合成点击 <500 ms 会被系统当双击**，WinUI Button 不触发第二次 `Click` | 连点取证要么换位置、要么间隔 >500 ms；不要据此判定产品 bug |
| 37 | **页面 `x:Name` 不是 UIA AutomationId**（除非显式设 `AutomationProperties.AutomationId`） | 用 x:Name 找页面元素会全部找不到；改用 `AutomationProperties.Name` 或显式 AutomationId |
| 38 | **UIA `IsOffscreen` 判不了被 Clip 裁掉的内容**（与坑 #17 同源） | 判断"是否被裁"用**页面根 vs 视口尺寸**或视觉对比 |
| 39 | **固定像素坐标点击在不同缩放档会错位**（曾把 Step4 误拍成"Step1"） | 一律用 UIA 定位元素中心后再点击 |
| 40 | **抓帧后立刻 `Bitmap.Save` 会吃掉时间**（10 张 1440×900 PNG ≈ 1.7 s） | 先把整段 burst 留在内存，全部动作结束后再统一落盘 |
| 41 | **`-f` 运算符在方法参数里会被逗号截断** | 先 `$row = '...' -f ...` 再 `.Add($row)` |
| 42 | **诊断日志文件路径不要写在受管作业的 stdout 里**（易被截断） | 写到 `%TEMP%` 再单独读 |
