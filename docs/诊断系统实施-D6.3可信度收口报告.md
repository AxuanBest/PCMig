## 一、本轮做了什么（范围与方式）

**输入**：D6.2 真实验证（`docs\诊断系统实施-D6.2真实验证报告.md`）+ 独立 GPT 复评（Reliability Audit）结论 —— **Stage B = NOT READY**，理由是诊断系统在五个词上仍可能说假话。

**范围纪律（本轮自缚）**：

1. **只修审计已证的缺陷**：凡不能"先造出红灯、再修绿"的，一律不改；
2. **不重设计、不加架构、不新增事件计数**（事件目录总数仍 140：106 Produced / 12 Deep-only / 22 Reserved）；
3. **不做大规模性能测试**（只做飞行记录器触发并发下的生产者延迟基准，WP-T）；
4. **不改业务语义**：所有改动限于"观测侧如何说真话"，业务行为（拷贝、暂停、恢复、校验）保持不变；
5. **修复后必须三件套**：红灯回归夹具 + 真实 UI 复验 + 重新导出包验证。

**方式**：真实 WinUI 应用（`PCMig.WinUI.exe`）在真机上跑真实迁移（源 `DESKTOP-5CSN7PT` 经 SMB 拉取 20,306 文件 / 1.54 GB 数据集），用 UIA 工具 `ui.ps1` 真实点击，用 `d63-tree.ps1` / `d63-dump.ps1` 读取真实控件树，用真实故障注入（同名目录占位、独占句柄、sink 存储故障）制造红灯。

## 二、收口目标：五个词必须说真话

| 词 | 修复前的风险 | 收口后的判据（不变量） |
| --- | --- | --- |
| **Complete** | 有序列空洞 / 未声明丢失 / 跳过损坏行时仍可能自称完整 | 只有"无空洞、无未声明丢失、无跳过损坏行"才允许 Complete |

| **Included** | 按"配置意图"冒充"包里真的有" | 只有真的在 ZIP 里才允许 `included=true` |
| **Healthy** | writer / analyzer / scheduler / flight / export 故障下仍自称健康 | 任何影响证据可信度的故障都必须降级，并说明降级原因 |

## 五、WP-A：证据闭合（序列水印）

**缺陷**：JSONL 段写入是按序号落盘的，但"连续水位"曾经可以越过一个**从未到达**的序号 —— 于是丢事件在证据里变得不可见。

**修复**：新增 `src\PCMig.Diagnostics\SequenceLedger.cs`：

- `BeyondCapacity = 8192`：超过容量不再假装知道，而是进入 `TrackingOverflowed`；
- 状态位：`Contiguous` / `SettledMax` / `SettledCount` / `WrittenCount` / `DroppedCount` / `TrackingOverflowed` / `UnknownCount` / `FirstUnknown` / `HasUnknownGap`；
- 结清入口：`SettleWritten(long)` / `SettleDropped(long)`，全部在 `_gate` 下；
- `src\PCMig.Diagnostics\JsonlSegmentWriter.cs` 在真正写盘成功后调用 `_ledger?.SettleWritten(evt.Sequence);`。

**下游**：`DiagnosticRuntime.PrepareExportCutoff` 的 `flushStatus` 只允许 `no-writer | seal-failed | no-active-segment | tracking-overflow | gap | tail-pending | acknowledged` 之一 —— **只要不连续就永远拿不到 `acknowledged`**。

**夹具**：`tests\PCMig.Diagnostics.Tests\D63EvidenceClosureTests.cs`（252 行）
`Fixture1_SequenceGapStopsTheContiguousWatermark`、`Fixture1b_TheHoleMustActuallyArriveBeforeTheWatermarkMoves`、`AccountedDropFillsTheHoleButIsNeverWashedAway`、`GapTrackingOverflowMustSayIDontKnowRatherThanClaimComplete`、`NonPositiveSequencesAreIgnored`、`Runtime_AccountedIngressDropKeepsTheWatermarkContiguousYetStillDegradesHealth`、`Runtime_CutoffNeverSaysAcknowledgedWhileEvidenceIsNotContiguous`、`Runtime_CutoffWithZeroBudgetCannotPretendToBeContiguous`。
