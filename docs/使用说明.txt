================================================================
PCMig 迁移工具 v0.2.5 —— 使用说明
企业内网 Windows 数据 / 用户环境迁移（直拉模式）
================================================================

■ 这是什么
  在【新电脑】上运行本工具，输入【旧电脑】的 IP 或电脑名，
  把旧电脑共享出来的磁盘数据完整拉取到新电脑。
  支持：暂停 / 继续、断网断电后断点续传、迁移后数据校验、HTML 报告。

■ 使用前准备（旧电脑侧）
  1. 旧电脑开机并接入内网。
  2. 开启磁盘共享（或确认管理共享 D$ / C$ 可用）。
  3. 准备一个旧电脑上的管理员账号（域管理员可直接用）。
     注意：Win7 目标若使用本地管理员账号，需用内置 Administrator
     （其他本地管理员会被 UAC 远程令牌过滤拦截）。
  4. 防火墙放行“文件和打印机共享 (SMB-In)”。

■ 图形界面用法（PCMig.exe）
  ① 输入旧电脑 IP/电脑名 + 管理员凭据 → 点【连接并列出共享】
     · 主机框支持直接粘贴 \\IP\共享名（如 \\192.168.1.50\D$），连接后自动定位该共享
     · 用户名/密码可留空：此时用当前 Windows 身份直连（同资源管理器）；
       若对方拒绝，会明确提示需要输入凭据
     · 若该电脑有未完成的迁移任务，会自动弹窗询问"是否从中断处继续"
  ② 选择要迁移的内容：
     · 目录树（默认）：共享=根节点。勾共享=整盘；点 ▶ 就地展开，
       目录和文件都可勾选。勾父级=子项全带；取消某子项→父级变半勾 ■，
       其余保持勾选。半勾父级再点=恢复全勾。
     · 超大数据模式（勾选右上角开关）：上亿文件/几十 TB 的服务器级
       迁移专用。目录树替换为「共享勾选 + 排除规则输入框」，规则每行
       一条：/XD 目录名或路径、/XF 文件名或通配符（裸词按目录处理，
       # 开头为注释）。规则与扫描、传输、验证同口径，并存入任务档案。
  ③ 选择目标路径（新电脑接收数据的位置）与线程数：
     · 线程数即 robocopy /MT（8/16/32/64/128，默认 16）：
       海量小文件或大文件多时调高（64/128）更快；机械硬盘或网络
       较差建议 8/16。线程数随任务存档，续传沿用。
  ④ 点【预检并生成计划】→ 确认对象清单与总量
  ⑤ 点【开始迁移】
     - 【暂停】：传完当前对象后停止（协作式）
     - 【立即停止】：立刻终止当前传输，已传部分保留，可续传
     - 【恢复任务】：从中断处继续（已完成的对象不会重传）
  ⑥ 完成后点【验证】核对数据一致性，【打开报告】查看 HTML 报告

■ 断点续传提醒（断电/断网/误关窗口后）
  · 重新打开工具、连接同一台旧电脑时，如发现上次任务未完成，
    会自动弹窗询问"是否继续"；选【是】即从中断处续传，已完成的
    部分不会重传（以每个对象的完成凭证为准）。
  · 生成新计划时若检测到同主机+同目标有未完成任务，同样会提醒。
  · 命令行下：直接运行 pcmig-cli resume（不带参数）会自动选择
    最近的未完成任务继续；quick/new 加 --yes 时检测到未完成任务
    会自动续传而不是新建。

■ 命令行用法（pcmig-cli.exe，以下 pcmig 均指 pcmig-cli.exe）
  预检:   pcmig-cli preflight --host 192.168.1.50 --user OLD-PC\Administrator
  一条龙: pcmig-cli quick --host 192.168.1.50 --target D:\ --user OLD-PC\Administrator
  指定源: pcmig-cli new --host H --source \\H\D$ --target D:\ --yes
  精细选择: pcmig-cli new --host H --source \\H\D$ --target D:\ --yes
            --paths "\\H\D$\图纸;\\H\D$\报表\总结.xlsx"   （分号分隔，可混目录与文件；quick 同支持）
  线程数:  加 --threads 64   （8/16/32/64/128，默认 16，随任务存档）
  排除规则: --xd "node_modules;临时目录" --xf "*.tmp;*.iso"   （分号分隔多项）
  传输:   pcmig-cli run --job <JOB-ID>
  暂停:   pcmig-cli pause --job <JOB-ID>      （协作式）
  急停:   pcmig-cli stop --job <JOB-ID>       （立即）
  恢复:   pcmig-cli resume --job <JOB-ID>
  状态:   pcmig-cli status --job <JOB-ID> [--watch]
  验证:   pcmig-cli verify --job <JOB-ID> [--level 2]   （level 2 含哈希抽样）
  报告:   pcmig-cli report --job <JOB-ID> [--open]
  列表:   pcmig-cli list

■ 不会迁移的内容（安全边界）
  × 浏览器密码 / 网站登录状态（DPAPI 绑定源机，搬过去也解不开）
  × Windows 凭据、证书
  × 驱动程序、安全软件（GlobalProtect/DLP/EDR 由 IT 统一装）
  × 回收站、休眠文件、pagefile 等系统垃圾（见 matrix 策略）
  → 新机首次使用：浏览器和邮箱需要重新登录，属正常现象。

■ 日志位置（排障必备）
  应用日志: C:\ProgramData\PCMig\Logs\app-*.log / *.jsonl
  任务日志: C:\ProgramData\PCMig\Jobs\<JOB-ID>\logs\
            ├─ job-*.log        任务级日志（文本）
            ├─ job-*.jsonl      结构化日志（可程序分析）
            └─ robocopy\*.log   每个对象的 robocopy 原始日志
  任务状态: C:\ProgramData\PCMig\Jobs\<JOB-ID>\
            ├─ job.json / plan.json / job-state.json
            └─ receipts\        每个对象的完成凭证（断点恢复依据）

■ 常见问题
  Q: 提示无法连接 \\IP\IPC$？
     A: 按顺序检查：目标开机 → IP 正确 → 防火墙 SMB-In → 账号密码 →
        Win7 用内置 Administrator。
  Q: 中途断电/断网了怎么办？
     A: 什么都不用做。重新打开工具，选择该任务点【恢复任务】即可。
  Q: 传输速度异常慢？
     A: 检查网线是否千兆、源机是否机械硬盘、是否有安全软件扫描。
  Q: 报告里“完成(有错误)”？
     A: 打开 HTML 报告看对象明细的错误列，通常是源端文件被锁定
        （让用户退出对应软件后，对该任务重新恢复运行一次即可）。

■ 技术要点（给 IT）
  - 传输引擎: Robocopy 双通道（/MT 多线程批量 + /Z 大文件可续传）
  - 断点机制: 对象级 Receipt 凭证 + robocopy 增量语义，重复执行安全
  - 验证: L1 文件数/字节对账，L2 抽样 SHA-256
  - 策略: matrix\migration-matrix.yaml（排除名单/大文件阈值/凭据边界）
  - 超大规模设计（面向服务器级数据量）:
    · 全程流式枚举，计数用 64 位整型，理论上限 800 万 TB / 92 亿亿个文件
    · 传输进度直接解析 robocopy 输出累计，不反复枚举目标目录
    · 验证器文件清单超 200 万条自动切流式核对（内存有界，结果同样精确）
    · 目录树单目录文件显示上限 5000（勾选目录即含全部，仅影响显示）
    · 目录遍历为迭代式（无递归栈深度限制）；已开启长路径（>260 字符）支持
    · 目标盘空间守护：计划总量超过可用空间时明确阻断/确认
