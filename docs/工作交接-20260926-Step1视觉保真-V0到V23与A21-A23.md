## 3. 本会话完成的工作（含根因）

### 3.1 D1 — 共享卡片空状态被裁切
- **根因**：卡片内层 Grid 为 `Auto/Auto/*`，空状态与 ListView 同处星号行；星号行仅 50 DIP、扣 Margin 后单元格 36 DIP，而空状态固有高 93 DIP 且 `VerticalAlignment=Center` → 顶部越界被裁。InfoBar（64 DIP）是直接消耗量。
- **修法**：行定义改 `Auto/*`；**删除卡片内 InfoBar**（状态文本改绑底栏，业务语义零丢失）；空状态容器改 `Grid.Row="1"`。
- **主控收口**：曾按指令加 `MinHeight="120"`，实测容器 120 > 星号行实得 114 → **反而把次级说明顶出卡片被横切**，已移除。**教训：加"保险"尺寸前必须核对可用行高。**
- 探针证据：`archive\winui-d1-probe\layout.json`（修前）/ `layout-fixed.json`（修后）。

### 3.2 D1-V9 回归（记为 D4）
- **事实**：V9 插画把空状态从 93 DIP 撑到 **187.2 DIP**，超出单元格 15.2 DIP → 第三行被切 7.4 DIP。
- **修法（未用固定 Height/MinHeight 硬塞）**：插画按参考比例缩到 **116×88**、文字间距 9→8；其余空间从连接卡 padding(16→14)、行距(12→10)、下一步按钮外边距(16→12)、Shares 卡 padding(16→14) 腾出。
- **修后实测**：`desired=actual=172`、单元格 **188**、第三行底 706.6 vs 单元格底 715.2（**余 8.6 DIP**）。
- 证据：`archive\winui-d1-probe\v9-layout.json`。

### 3.3 D2 — 截图流污染（含一次严重事件）
- **根因**：`GetWindowRect` 对 DWM 合成窗口返回**含不可见调整边框+阴影的扩展框**（本机横 16px、纵 8px），按它 `CopyFromScreen` 必然把窗口外桌面/任务栏拍进来。
- **修法**：改用 `DWMWA_EXTENDED_FRAME_BOUNDS(9)`。
- **严重事件**：某次"看起来正常"的截图**实际拍到的是浏览器里的 ChatGPT 页面**——`CopyFromScreen` 抓屏幕像素，而脚本只把窗口移到 (0,0)（传了 `SWP_NOZORDER`）却没置顶。
- **加固（物理上不可能拍错）**：临时 TOPMOST → `WindowFromPoint + GetAncestor` **抓取前后各一次自检**，任一失败**直接拒绝出图**（`exit 3/4`）；并顺带用中性点击消除输入框的聚焦下划线。脚本：`archive\scripts\winui-capture-region.ps1`。

### 3.4 DPI — 进程不感知
- **根因**：`app.manifest` **完全没有 DPI 声明** → 125% 下被系统 1.25× 位图拉伸（`RasterizationScale=1`）。
- **修法**：声明 `PerMonitorV2`（`dpiAware=true/pm` + `dpiAwareness=PerMonitorV2, PerMonitor`）。
- **关键陷阱**：声明后 `AppWindow` 尺寸单位变为**物理像素**，原 `Resize(1440,900)` 会把 XAML 空间压成 1139×713 DIP。
- **更深的坑**：`AppWindow.ResizeClient(w,h)` 的"客户区"**不含** `ExtendsContentIntoTitleBar` 覆盖的那条标题栏带，系统**固定多给 38px（29.8 DIP）** → 必须"**先量常量偏移、再从请求值扣掉**"，而不是按增量补；且 **`SizeChanged` 订阅必须早于首次 `ResizeClient`**（首次布局可能是同步完成的，否则事件永不触发）。
- **结果**：XAML 视口锁定 **1424×891.2 DIP**，accent band 与基线逐条重合。

## 4. 机制级根因清单（下一位接手者最该先读）

1. **`ThemeShadow` 必须配 `Translation` Z 才会投影**；且 **`Translation` 不能写进 Style Setter**（`WMC0095`，非 DP）→ 只能内联/ControlTemplate。
2. **`AppWindow.ResizeClient` 的客户区不含 ExtendsContentIntoTitleBar 覆盖的标题栏带**，系统固定多给 38px（本机 125% 实测 +29.8 DIP）→ 尺寸必须"量常量偏移再扣"，且 `SizeChanged` 订阅要早于首次 resize。
3. **字体度量导致"看起来没居中"**：TextBlock 的墨迹中心比其盒中心高；`Border(Padding)+TextBlock` 组合在**拉伸**容器里会让文字渲染在盒顶（A23 的根因）。→ 统一对策：显式 `VerticalAlignment="Center"`、必要时用 `Translation`/非对称 padding 微调，**先探针测盒、再像素测墨迹**。
4. **环境光"给了但看不见"= 数值太小**（opacity 0.06–0.11、alpha 5–8%）。
5. **`CopyFromScreen` 抓的是屏幕像素**：不置顶就可能拍到别的程序（实测拍到浏览器 ChatGPT）→ 必须 TOPMOST + 前后自检。
6. **`GetWindowRect` 对 DWM 窗口返回含不可见边框+阴影的扩展框** → 必须用 `DWMWA_EXTENDED_FRAME_BOUNDS`。
7. **`Controls.xaml` 最后合并 → 对框架默认 `TextControl*` 键的覆盖生效**（V7 的前提）。
