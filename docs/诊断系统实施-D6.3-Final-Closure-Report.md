### R-1 Flight Recorder post 丢包闭环

根因（复核者结论，本轮复现确认）：`FlightEvidenceIncomplete` 在全仓库只有「声明 / 读取 / 写出 / 加 blocker」四处命中，**没有任何赋值点** ⇒ `flight-evidence-incomplete` blocker 生产不可达；post 窗口超容量与超载荷预算两处只做 `window.DroppedInPost++ / _dropped++`，不像环路径那样走 `_loss.RecordDrop(...)` ⇒ 不进 LossLedger、不动健康、不进 cutoff；而包内该窗口的清单却会写 `partial: true`。

修复（6 处）：

1. `src/PCMig.Diagnostics/FlightRecorder.cs` 新增只增不减的聚合 `private volatile bool _evidenceIncomplete;` 与 `public bool EvidenceIncomplete => _evidenceIncomplete;`。
2. `Observe` 的 **post 超容量**分支：置位 + `_loss.RecordDrop(DiagnosticBranches.Flight, evt.Delivery, evt.Sequence, "post-window-capacity", evicted: false)`。
3. `Observe` 的 **post 超载荷预算**分支：置位 + `_loss.RecordDrop(..., "post-window-budget", evicted: false)`。
4. `PersistWindow`：`if (!complete) _evidenceIncomplete = true;`（`complete = window.PostComplete && window.DroppedInPost == 0`）。
5. `PersistWindow` 的 catch（落盘失败）：置位。
6. `SealOpenWindows` 的 `notReady > 0`（pre-copy 仍在飞行、窗口未封全）分支：置位。

判据接入：`src/PCMig.Diagnostics/DiagnosticRuntime.cs` 的 `PrepareExportCutoff` 新增 `var flightIncomplete = _flight?.EvidenceIncomplete ?? false; if (flightIncomplete) blockers.Add("flight-evidence-incomplete");`，并把 `FlightEvidenceIncomplete = flightIncomplete,` 写入 `DiagnosticExportCutoff`（该字段此前恒为 `false`）。于是链路闭合为：**post 丢包 → LossLedger + `EvidenceIncomplete` → cutoff 字段与 blocker → manifest/summary 同口径 Partial/`packageEvidenceComplete:false`**。

夹具：`tests/PCMig.Diagnostics.Tests/D63ExportTruthTests.cs` 新增 `R1_PostWindowLossMustReachTheLedgerAndBlockCompleteEvidence`（环容量 2 / 环字节预算 64 KB / post 窗口 400 ms / 触发冷却 1 ms；触发飞行后连发 20 条 post ⇒ 断言 `health.EventsDropped >= 1`、`health.IsDegraded`、`!health.EvidenceComplete`、`cutoff.FlightEvidenceIncomplete`、`!cutoff.IsPackageEvidenceComplete`、包内飞行清单 `partial: true`、manifest `cutoff.flightEvidenceIncomplete: true` + blocker、summary `packageEvidenceComplete: false` 且非 Complete）；`D63FlightTruthTests.cs` 两条既有夹具补单元级守卫（`Assert.True/False(recorder.EvidenceIncomplete, ...)`）。`Start(...)` 助手新增 `Action<DiagnosticRuntimeOptions>? configure` 形参以便注入上述选项。
