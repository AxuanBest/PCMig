## 4. 一个方法论要点（本轮踩到，值得固化）

**调"某个区域"的颜色时，不要顺手改共享的材质 tint。** 本轮为把插画区调亮，先改了 `SecondarySurfaceBrush` 的 TintColor，结果该区主色没变、**整屏反而更暗**（#E4E4F4 → #E2E2F4），因为 tint 影响所有卡片。正确做法是：**只改该区域自己的矢量填充**（本轮改成后背层/面板/光晕三处后，该区均色与主色占比都向参考靠拢）。
