### C-02｜**错误 67 完整预检链路**（对方不导出 IPC$）

| 项 | 内容 |
|---|---|
| **为什么必须** | 本机 IPC$ 始终可用，**无法制造"不导出 IPC$ 的 SMB 服务端"**。真实文本样本已验证可正确提取 67，但**链路层未验证**。 |
| 步骤 | 找一个不导出 IPC$ 的对端（精简 SMB / NAS / 第三方 SMB 服务，或策略关闭管理共享的机器），执行 `pcmig preflight --host <对端> --user U --password P` |
| 预期 | 出现 `Win32Error=67`；PCMig **不阻断**，自动改用直连共享；输出含"对方不导出 IPC$…不影响迁移，将改直连共享"这类说清语义的文案（`NetworkShare.cs:208-244`） |
| 证据 | 预检输出全文 + `preflight.json` |
| 记录 | 结果：☐ PASS ☐ FAIL ☐ BLOCKED（若全公司 IPC$ 都正常，记 BLOCKED 并注明"环境不具备"） |

### C-03｜**1219 连接冲突**（真实多凭据）

| 项 | 内容 |
|---|---|
| **为什么必须** | 需"本机已有到该机的**另一组凭据**的连接"。回环用登录令牌，显式凭据**不产生冲突**（已实测）。这是公司血泪教训（v0.2.8–2.9）。 |
| 步骤 | ① 先在资源管理器打开 `\\旧机名`（或用别的凭据 `net use`）<br>② 然后用**另一组凭据**跑 `pcmig preflight --user U --password P` |
| 预期 | 出现 1219；PCMig **复用现有连接而非杀掉会话**（`NetworkShare.cs:185-199`；公司教训：目标可能无 IPC$，杀了重试必败）；文案说清"接下来怎么办" |
| 证据 | 预检输出 + `net use` 快照 |
| 记录 | 结果：☐ PASS ☐ FAIL ☐ BLOCKED |

## 二、P1 —— 应当验证（影响可信度）

### C-06｜企业 DNS / NetBIOS / 电脑名解析

- **为什么**：私人环境只有短名 `AXUAN`，**FQDN 未测**；公司常见"电脑名解析到失效旧 IP"（v0.2.26 修过预检误报）。
- **步骤**：分别用短名、FQDN、IP 三种目标各跑一次 preflight；构造"电脑名指向已失效 IP"的场景。
- **预期**：短名/FQDN/IP 都可用；失效旧 IP 不再造成预检误报。
- 记录：☐ PASS ☐ FAIL ☐ BLOCKED

### C-07｜企业管理共享策略与权限模型

- **为什么**：私人管理共享由本机默认导出；**公司可能被组策略关闭/改名**（v0.3.8 实测过"域策略刷新关掉 D$"）。
- **步骤**：确认目标机 `net share` 实际导出；用域管理员与普通域用户各跑一次 `--source \\旧机\D$`。
- **预期**：策略关闭 `D$` 时，报错**点名数据共享**而不是误导成 IPC$ 的 67（`NetworkShare.cs:312-313` 已修）。
- 记录：☐ PASS ☐ FAIL ☐ BLOCKED

### C-08｜企业安全软件（EDR / DLP / 杀软）干扰

- **为什么**：私人环境**明确不安装来源不明的内核级软件**（用户硬要求）。
- **步骤**：在装有公司 EDR/DLP 的机器上跑一次完整迁移；观察是否被拦截、是否掉速、是否有文件被隔离。
- **预期**：迁移可完成；被拦截时有可读文案而非静默失败；必要时记录需加白名单的进程/路径。
- 记录：☐ PASS ☐ FAIL ☐ BLOCKED

### C-09｜企业网络条件（VPN / 代理 / 网段隔离 / 防火墙）

- **为什么**：私人环境是家用路由 NAT，无企业边界设备。
- **步骤**：在公司网/VPN 下验证：445 可达性、跨网段 SMB、防火墙拦截时的报错可读性。
- **预期**：预检能明确定位是 445 不通、DNS 不通还是共享不可用。
- 记录：☐ PASS ☐ FAIL ☐ BLOCKED

### C-10｜非管理员账号运行 PCMig

- **为什么**：私人环境全程 Medium 完整性但**不是域受限用户**。
- **步骤**：用**普通域用户**（非管理员）运行 GUI 与 CLI 各一次。
- **预期**：明确的可读提示或可降级运行；不静默失败。
- 记录：☐ PASS ☐ FAIL ☐ BLOCKED

## 七、边界声明（不得夸大）

1. 私人环境 **L3 Corporate Simulation 尚未执行**（无 Windows Server 介质）→ AD/DNS/域用户/GPO **全部仍是 `COMPANY_ONLY`**。
