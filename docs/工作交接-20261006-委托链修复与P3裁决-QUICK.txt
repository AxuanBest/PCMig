【环境踩坑（省几小时）】
  ★ 火绒安全（HipsDaemon / HipsTray / wsctrlsvc）会静默拦截本机文件写入：write 报
    「Created file」但无产出、含写入的 pwsh 命令输出被整体丢弃、只读正常。本会话就撞过，
    用户关闭火绒后立即恢复。判定特征 = 只读正常 + 写入静默失效 + 同命令内重试也无效。
  · PS 5.1 把无 BOM 的 .ps1 按 GBK 解码 → 中文吞引号报 Missing ')'。规则：.ps1 前三字节
    必须是 EF BB BF；write 工具产出无 BOM，改完必须复查。
  · $args / $Pid / $host / $HOME 是只读自动变量，不能当参数名或赋值。
  · [IO.File]::ReadAllText('相对路径') 按进程 CWD 解析 ⇒ 一律绝对路径。
  · 本机 IsAdmin = False ⇒ New-SmbShare 拒绝、Mount-DiskImage 报「客户端没有所需的特权」
    （无法把 VHDX 挂成小卷）。**造盘满改用 fsutil file createnew <卷>\filler.bin <字节数>**。
  · WinUI 树/列表虚拟化 ⇒ 每次操作前重新抓取 UIA 节点，别复用上一帧坐标。
  · Shell.Transfer.Start 对真实鼠标点击无效 ⇒ 必须用 InvokePattern。
  · Step2 树根 = 已勾选共享的集合 ⇒ 夹具只保留目标共享勾选，否则目标被挤出虚拟化窗口。
  · 共享 CheckBox 与树 CheckBox 都可能默认 On ⇒ 仅当 Off 时才 Toggle。
  · 同主机 + 同目标目录命中未完成任务会弹续传对话框阻塞 Prepare ⇒ 夹具每轮用唯一目标目录。
  · 本机窗口激活只认 Shell.Application 的 MinimizeAll()/UndoMinimizeAll()。
