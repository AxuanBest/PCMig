## 2. 液态透明专项调查（**本轮核心产出，结论已定，待用户规划**）

### 2.1 三步判决实验

| # | 实验 | 结果 |
|---|---|---|
| 1 | 删掉自绘整窗底色矩形（保留 Mica） | 窗口均值 `#E0DEF3 → #E3EAF4`，画面更均匀、图像体积从 1.5MB 降到 0.93MB → **说明 Mica 确实在采样桌面** |
| 2 | 背景材质换 `DesktopAcrylicBackdrop` | 仍偏冷偏白（`#E8EDF5`） |
| 3 | tint 压到 **0.05** + 桌面壁纸临时换**纯品红 `#C8008C`** | 窗口均值仍只从 `#E8EDF6` 动到 `#E8EBF5` → **证明现有路径下"真透明"未生效** |

### 2.2 结论（下一位必读）

- 参考图的粉/蓝紫**确实来自壁纸经"液态透明"透出**，用户口径正确。
- 但 **WinUI 的 Mica / DesktopAcrylic 会对壁纸做重度去饱和 + 提亮**，无论壁纸多鲜艳，透出来都是冷白蓝。
- 本机壁纸是 Windows 默认 `C:\WINDOWS\web\wallpaper\Windows\img0.jpg`（3840×2400，暖红，实测均色 `#DDC4C1`），与参考稿所用极光壁纸完全不同 → **在同一条路径上不可能复现参考的光色**。
- **实验用临时壁纸已全部撤掉，用户壁纸已按原值还原**（留档 `stage9\evidence\original-wallpaper.txt`，注册表复核 = img0.jpg）。实验截图留档：`v17-liquid-probe.png`（Mica 无自绘）、`v17-acrylic-probe.png`、`v17-alpha005.png`、`v17-liquid-magenta.png`（品红壁纸）、`v17-liquid-aurora.png`（极光壁纸）。

### 2.3 待用户规划的候选方向（**不擅自开工**）

1. 接受系统材质限制，把自绘氛围做回一档浓度（简单、环境无关）；
2. 走**真正的 Composition 背景模糊**（自建 backdrop 视觉层，绕开 Mica 的去饱和）；
3. 改判定口径：把"液态透明"视为**依赖壁纸的环境相关表现**，V12 只判"结构 + 组件质感"。
