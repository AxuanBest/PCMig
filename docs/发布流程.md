# PCMig 发布流程（发版人必读）

> 强制约束见 **`docs/发版铁律.md`**（死条律）；本文件是它的操作版。
> 本机（个人电脑）交付区 = **`<交付区>`**；权威工作区 = **`<仓库根>`**。

一句话铁律：**先写日志，再打包；没写日志就打不出包。**

## 为什么要定这个流程

v0.2.24 之前，更新日志是事后靠考据补出来的（翻历代说明书、测试报告、会话记录），
花了很大力气还只能做到"个别版本可能有 ±1 个版本的误差"。
从 v0.2.25 起改为**每版发版时同步写日志**，日志永远是第一手记录，不再需要事后考古。

## 发一版只需两条命令

    # 1) 先把这一版改了什么写进三处（见下面清单）
    # 2) 打包（脚本会先校验，缺一项就拒绝打包）
    powershell -NoProfile -ExecutionPolicy Bypass -File "<仓库根>\tools\release.ps1" -Version 0.5.1

## 发版前必须写好的三处（脚本硬校验，缺一项中止）

1. docs\更新日志.md
   * 顶部「版本号与发布日期对照」表新增一行：| vX.Y.Z | 发布日期 | 主题 |
   * 正文按新到旧顺序，在最新位置插入一节：## vX.Y.Z — 主题
   * 写清 背景 / 改了什么 / 为什么（根因），措辞面向使用者，不写内部隐私信息
2. docs\使用说明.txt
   * 顶部新增一段：■ vX.Y.Z ...（用户视角：这一版对他意味着什么）
3. 版本号
   * 脚本自动改：Cli / Core / Gui / **WinUI** 四个 csproj 的 `<Version>`、两个 MainWindow.xaml 的窗口 `Title`、
     **WinUI MainWindow.xaml 里两处运行时可见的版本徽章 `Text="vX.Y.Z"`**（标题栏版本文字 + 更新日志按钮徽章）、
     README.md、installer\pcmig.iss（MyAppVersion 与 VersionInfoVersion），改完逐个自查
   * ⚠ v0.5.1 起：`src\PCMig.Gui`（旧 WPF）**仍随源码树一起改版本号**，但它已不进入正式交付物（见铁律 13-A）

## 脚本自动做的其余步骤

1. 校验上面三处 → 生成 docs\更新日志.txt（UTF-8 带 BOM + CRLF，记事本直接可读，内容与 md 同源）
2. dotnet publish（**WinUI 主界面 + CLI**）→ 组装 dist\app（含 更新日志.txt、使用说明.txt、matrix）
   * v0.5.1 起**不再 publish 旧 WPF 前端**，dist\app 里不得出现 PCMig-classic.exe / PCMig.exe（脚本硬门禁，三处断言）
3. ISCC 编译安装包 → 交付到 <交付区>、<交付区>\Portable、工作副本 <发版工作副本>
4. 逐文件哈希比对（WinUI 两处、CLI 两处、安装包、更新日志.txt、使用说明.txt，共 **7 组**），不一致就中止
5. 列出交付区并列的历史安装包（**只列不删，一律全量保留**）、启动工作副本 **WinUI** 自检（源码镜像默认关闭，$mirror 留空）

## 发版后必须做的验证（不接受"看起来没问题"）

1. 三处入口都能看到本版日志：应用内「更新日志」窗口（本版应被默认选中）、程序根目录的
   更新日志.txt（记事本打开）、命令行 pcmig changelog。
2. 受影响的界面用两种独立方式确认：tools\uishot.ps1 截图 + 视觉模型自查，并用 UIA 读真实控件树复核。
3. 涉及勾选/计划/传输逻辑的改动，先跑模型级回归测试：
   <旧镜像根>\labs\TreeTest（直接编译 GUI 真实源码文件，测状态与变更通知）
4. 把本轮的根因、修法、验证方式追加到 docs\测试报告-公司环境.md。

## 已经踩过的坑（写在这里免得再踩）

* WPF 里 Set(ref _field, value) 的 [CallerMemberName] 取的是**调用它的方法名**。
  在 SetCheckedSilent 这种包装方法里必须显式 OnPropertyChanged(nameof(IsChecked))，
  否则绑定收不到通知——模型值对、界面不动，曾导致"勾整盘时散落文件不勾上"。
* PowerShell 里 @(...) 数组字面量中逗号优先级高于 +，'a' + $x + 'b' 会被拆成多个元素，
  改 installer\pcmig.iss 的版本号必须用正则替换或整行替换，且改完自查。
* 静默安装旧版本用于考古时必须装到无空格路径，否则 /DIR 会被截断。
