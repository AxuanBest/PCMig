## 2. 本会话新确认的环境事实

1. **`Border.Child` 不是 DependencyProperty** → 不能用 `<Setter Property="Child">` 给 `Border` 样式的卡片插"顶部亮线"子元素（**WMC0095: Property 'Child' must be a DependencyProperty to be set with a Setter**，四张卡一起报 4 个错）。
2. **`BorderBrush` 用 LinearGradientBrush 时，渐变坐标铺满整个 Border 盒**，1px 描边只能取到渐变在描边中线处的颜色 → **靠描边渐变做"顶亮侧淡"几乎不可见**（本会话实测两轮，行剖面在同一亮度带内看不到尖峰）。要做出参考那种"1px 白亮线"只有两条路：① 卡片内部加独立 1–2 DIP 的亮线 Border（**必须改 MainWindow 结构**）；② 改用 Microsoft.UI.Composition DropShadow/自定义绘制。
3. **修改超长单行 XAML 必须用"读全文 → String.Replace → 写回（带 BOM）"**，并用 `occurrences` 计数校验；直接用 edit 工具在 3000+ 字符单行里替换极易失败或错配（本会话 Materials.xaml 因括号错配写坏一次，已重写修复）。
4. 云端视觉工具（`vision_glance`/`vision_crop`）**坐标不可信、只当形态与观感裁判**；单次调用必须显式给 `timeoutMs`（建议 420000）。图片必须先复制进工作区。
5. 截图前置条件：**必须先抢前台**（ALT 键起落 + SetForegroundWindow），否则 `capture-exact.ps1` 会 `Foreground refused` 拒绝出图。已固化在 `launch-capture.ps1`。
6. 每次编辑 .ps1/.xaml 后**必须复查前三字节 `EF BB BF`**（本会话又补了多次，含 Materials.xaml 重写后）。
