## 一、项目概览

**PCMig**：企业内网 Windows 数据/用户环境迁移工具。直拉模式（Direct Pull）——在新电脑运行，输入旧电脑 IP/电脑名 + 凭据，通过 SMB 把旧电脑共享盘数据完整拉到新电脑。

- 技术栈：C# / .NET 8（WPF GUI + CLI）、Robocopy 传输引擎、Serilog 三层日志、Inno Setup 安装包、YAML 策略矩阵
- 核心机制：Data Plane（D 盘全量）/ State Plane（C 盘 Profile+Recipe）分治；双通道 Robocopy（批量 `/MT` + 大文件通道）；对象级调度；Receipt 只追加回执为权威状态（job-state.json 仅是视图，损坏可由回执重建）；协作式暂停；三级进度；L1 数量字节比对 / L2 抽样哈希
- 安全边界（V1 明确不做）：凭据/Cookie（DPAPI 绑定源机）、驱动、安全软件、整盘 ACL、Windows 系统目录 → 见 `matrix/migration-matrix.yaml` 的 `securityBlockedFileNames`
- 路线图：V1.5 Outlook/浏览器 Recipe、OneDrive KFM、零安装远程采集；V2.0 Win7 源兼容、winget 编排、GUI 多任务视图
