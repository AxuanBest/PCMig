## 2. 本会话新确立的环境事实（**下一位接手者必读**）

### 2.1 视觉通道（**上一份交接的"无视觉"结论已更新**）

| 通道 | 本会话实测结论 |
|---|---|
| `read_image`（主模型原生） | ❌ 仍不可用：`model "deepseek-v4.1-flash" does not declare image input` |
| **DSH 视觉工具包**（先调用 `vision_toolkit_activate`） | ✅ **可用**：`vision_glance`（描述/问答/对比）、`vision_crop`（裁剪放大）、`vision_ground`（定位框）、`vision_pixel_diff`、`vision_dominant_colors`、`vision_trace`、`vision_extract_foreground`；**走云端视觉模型**，单次调用可用 `timeoutMs` 放宽（实测 1586×992 全图问答约 1–3 分钟；**默认超时会失败，必须显式给 420000**） |
| **图片路径限制** | 视觉工具只接受**工作区内**路径（`<工作区根>\…` 或 `%TEMP%`）；桌面路径会报 `image escapes the allowed directories` → 必须先复制进工作区。本会话已把用户桌面 4 张参考图复制到 `archive\step1-fidelity-20260926-r2\ref-desktop-3\` |
| 云端视觉的可靠性 | **坐标估计不准**（实测把裁剪图坐标当原图坐标、误差可达 40+ px）→ **坐标一律以确定性测量为准**，云端视觉只用于**形态/观感/语义**判断（例：Logo 是几条箭头、朝哪边、有没有缺角；卡片有没有白边高光；整体像不像同一套设计） |

**结论**：本会话的视觉判断＝**云端视觉模型（形态/观感）+ 确定性测量（几何/文字/颜色/对比度）** 双轨；**"最终是否已是同一套视觉语言"仍必须由用户人眼认定**。

### 2.2 前台窗口与截图（**本会话踩到并解决的新坑**）

- 本机当前前台窗口是 Chrome；**DSH 自己的 pwsh 进程不是前台进程 → `SetForegroundWindow` 直接失败**（实测返回 False），而 `capture-exact.ps1 v2` 会因 `Foreground refused` 拒绝出图（这是它的安全设计，不是缺陷）。
- **解法（已验证）**：先注入一次**无害的 ALT 键起落**（`keybd_event(0x12,0,0)/(0x12,0,2)`，不改输入内容、不点击、不向被测程序写任何状态），系统随即放行一次前台切换，再 `SetForegroundWindow` 即成功。
- 已固化为新脚本 `launch-capture.ps1`（见 §3.5），它同时负责：启动 fresh EXE → 等真实 HWND → 抢前台（失败就**拒绝截图并杀进程**）→ 调 `capture-exact.ps1` → 跑 `ocr-image.ps1` → 杀进程 → **统计 WER 崩溃计数增量**。

### 2.3 其他坑（沿用上一份交接，仍然有效）

- dotnet 10.0.401；WinUI 加 `-p:Platform=x64` 时输出目录带 `x64` 段（`bin\x64\Release\…\win-x64\`），无 x64 段的是旧产物。
- 执行策略 Restricted → 所有 .ps1 必须 `powershell -NoProfile -ExecutionPolicy Bypass -File` 调用。
- **DSH edit 工具剥 UTF-8 BOM**（本会话又踩 1 次：Controls.xaml）；`write` 工具写的文件也**无 BOM**。**每次编辑 .ps1/.xaml 后必须复查前三字节 `EF BB BF` 并补回**（本会话新增 `scan-cells.ps1`、`launch-capture.ps1` 各补 1 次，`Materials.xaml` 补 1 次，`Controls.xaml` 补 2 次）。
- `New-JudgmentStage.ps1` 会**强校验 scripts 目录下每个 .ps1 的 BOM**，缺一个就整包失败。
- PS 5.1：`ConvertFrom-Json` 顶层数组要用 `-InputObject` + `| ForEach-Object { $_ }` 才展开；无 BOM 的 UTF-8 中文文件要用 `[IO.File]::ReadAllText(路径, [Text.Encoding]::UTF8)` 读、`[Text.UTF8Encoding]::new($true)` 写。
- **不要用 edit 工具改这些超长行 XAML**：MainWindow.xaml 的底栏/按钮都在单行 3000+ 字符里，edit 的 old_string 极易不匹配；本会话统一改为 **PowerShell 读全文 → `String.Replace` → 写回（带 BOM）**，并在替换前后做 `occurrences` 计数防误替。
