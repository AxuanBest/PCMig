## 2. P0（必须立即处置）

### P0-1　Deep Trace 记录**具体按键**，等于把口令敲击变成可导出的键盘记录

- **位置**：`src\PCMig.WinUI\Diagnostics\DeepTraceInputObserver.cs:139`
  ```csharp
  private void OnKeyDown(object sender, KeyRoutedEventArgs e)
      => Observe("key:" + e.Key, e.OriginalSource as DependencyObject);
  ```
  该字符串经 `UiInputObservedPayload(inputKind, ...)` 原样写进 `UI.InputObserved`，进入本地 `events\*.jsonl`。
- **为什么是 P0**：用户在开 Deep Trace 的情况下于「密码」框输入口令，`KeyDown` 会逐个触发，
  于是 `key:A`、`key:B`、`key:3`… 把口令**逐字符**写进诊断证据；导出包又只清洗 envelope 的
  `Path`/`Message`，**payload 原样进包**（`DiagnosticPackageExporter.cs:263-273`）⇒ 口令字符随包外发。
- **与规范直接冲突**：方案 §9 明确要求"记录 Pointer/Tapped/**导航键**类别和 ControlId，
  **不记文本键**、IME 内容、**敏感控件及其祖先内容**"。当前实现：① 记了**全部**按键而非导航键；
  ② `ResolveControlId`（`:206`/`:217`）只向上找 `AutomationId`，**完全没有 PasswordBox/敏感控件判定**。
- **复现证据**：`probe-results.json` → `INPUT_KEY_PAYLOAD_UNREDACTED = true`（3/3 轮）。
- **为什么绿测没抓到**：`tests\PCMig.Diagnostics.Tests\D5DeepTraceContractTests.cs:91` 断言的是
  `DoesNotContain("e.Key.ToString")` —— 而代码写的是 `e.Key`（没有 `.ToString()`），
  这条断言**恒真**，属"测试写法本身抓不到缺陷"。这是一条比缺陷本身更值得记住的教训。
- **建议最小修法**（待授权）：
  1. 只允许**导航/控制键白名单**（Tab / Enter / Escape / Space / 方向键 / Home / End / PageUp / PageDown），
     这类键只记类别 token（如 `key-navigation`），**永不记按键身份**；其余按键只记 `key-other`（无身份）；
  2. 命中 `PasswordBox`（或其祖先含 `PasswordBox`/敏感 ControlId）时**直接丢弃该事件**；
  3. 测试改为"断言记录里不出现按键身份、且 PasswordBox 场景零事件"，而不是断言某个不存在的字符串。

## 7. 处置建议（按优先级，均需你授权后执行）

1. **立即**：不要在真实凭据输入期间开启 Deep Trace；**不要把现有诊断包对外发出**（含 P0-1 与 P1-3 数据）。
2. **P0-1**：按 §2 的最小修法改 `DeepTraceInputObserver` + 重写那条恒真断言。
3. **P1-1/P1-2**：导出三份 JSON 一律改用 `Utf8JsonWriter` 生成；新增"每个 entry 必须能被 `JsonDocument.Parse`"的测试。
4. **P1-3**：`StorageRoot` 等 Personal 字段在**事件层**就令牌化；导出对 payload 做**结构化深扫**而非只清 envelope。
5. **P1-4**：每次 `Export` 现场生成新 key；如需"跨包不可关联"，manifest 不写原始 SessionId。
6. **P1-5/P1-6/P1-7/P1-8**：环覆盖不得计入 CriticalLost；`Depth` 改为真实计数；
   payload 用"实际序列化字节或按名分级上界"；`_finished` 加容量上限并释放已落盘窗口的事件列表。
7. **P1-9**：解析器对"未知 eventVersion"必须标记为未知并拒绝按当前版本解释；空 envelope 直接判失败。
8. **覆盖度**：要么把其余八条动作链接上（需要改 WinUI handler，属冻结范围，需你明确指令），
   要么把契约表降级为"仅连接已接入"并把其余标为未接入——**不能继续保留"已完成"的表述**。
9. **P2-1/P2-2/P2-3**：面板关闭/互切停表；导出移出 UI 线程；复验包补 `PCMig.sln` 并更正 `复验说明.txt`。
