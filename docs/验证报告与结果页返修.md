# 验证报告与结果页返修（v0.5.3 之后的候选改动）

本文件记录一次**验证语义收口**的设计与验收口径：结果页不再被对象编号铺满，验证进度改由应用内浮层承载，逐对象证据改由本地自包含 HTML 报告承载。

> 关联文档：[`PMML-UI修改硬性规范.md`](PMML-UI修改硬性规范.md)、[`PCMig-Visual-Motion-Language.md`](PCMig-Visual-Motion-Language.md)、[`诊断系统实施-事件覆盖矩阵.md`](诊断系统实施-事件覆盖矩阵.md)

---

## 1. 现场问题与根因

一次 400 个对象以上的验证之后，「结果与校验」正文与左侧提示卡同时被 `object-000001、object-000002、…` 铺满，真正要看的结论被淹没；同时验证过程只有"独立二级窗口"这一个出口，主页面无法表达"验证在跑、跑到哪了"。

根因是**两条写入链**：

1. 结论文案里把全部异常对象编号 `Join` 成一句话（`DescribeVerifyOutcome`），该文案又经状态通道同时被结果页正文与左侧提示卡消费；
2. 进度与逐对象明细没有类型化出口，只能塞进同一句话。

## 2. 收口后的口径

| 层 | 承载内容 | 硬约束 |
|---|---|---|
| 左侧提示卡 / 状态行 | **一句话结论**：状态 + 四态数量（如「L1 对账未通过：通过 1，差异 412，无法确认 0。」） | **一个对象编号都不出现** |
| 结果页正文 | 结论文案 + 示例编号 **最多 3 个**（超出写「如 … 等 N 个」） | 不拼接全量编号 |
| 验证浮层 | 真实进度：对象序号 / 已核对文件数 / 已核对字节 / 已用时间 / 四态计数 | 计数**只来自引擎实测累计值**，面板不估算、不预测 |
| 验证报告 HTML | 逐对象结论、差异文件清单、错误原因、建议操作、口径与限制 | 零外部引用，断网可看；与某一次已完成验证绑定 |

**状态语义**：`OK`（通过）/ `MISMATCH`（存在差异）/ `UNKNOWN`（无法确认，如源或目标不可达、枚举不完整）/ `EMPTY`（计划与实测都为空，不算传成功）/ `CANCELED`（没有结论）。只有 `MISMATCH` 允许进入破坏性修复。

**级别口径**：L1 只核对**文件数量与总字节**，通过时不得说成"内容一致"；L2 是**抽样**哈希，不得说成"全文件已哈希"。

## 3. 验证报告（本地自包含 HTML）

- 章节：`00 页眉` / `01 人话结论` / `02 概览统计卡` / `03 环境档案` / `04 逐对象结果表` / `05 文件级差异表` / `06 验证步骤进度表` / `07 错误与建议` / `08 统计口径与限制` / `09 关联迁移证据`。
- 大对象量：首屏 200 行，其余按批「显示更多」；表头可排序、可按关键字筛选。
- 有界：引擎记录的差异样例有上限（默认 50 条），报告里显式写明「样例条数不是缺失总数」。
- 不编造：历史报告缺字段时显示「未采集」并说明该报告由旧版本引擎产生。
- 取消 / 中断：允许生成**诚实的部分证据报告**（写明"取消不等于通过"），但不生成空报告冒充结论。
- 文件名带运行号后 6 位（`verify-report-<时间戳>-<运行号>.html`），连续两轮不会互相冒充。

命令行入口：`pcmig verify-report --job <JOB-ID> [--open]`（没有验证报告时明确拒绝，不生成空报告）。

## 4. 打开方式与按钮语义

- 结果页保留既有「打开报告」= **迁移报告**（迁移事实与回执）。
- 验证浮层新增「打开验证报告」= **验证报告**（本轮核对到了什么）。
- 两者都只用系统默认浏览器打开**本地** `.html`；打开失败时给出可复制的本机路径，不假称成功。

## 5. 验收口径（摘要）

| 项 | 判据 |
|---|---|
| 结果页 | 大对象量验证后正文无成串对象编号；原有按钮、失败列表、实时日志、页面导航全部可用 |
| 提示卡 | 只有一句话结论（一个对象编号都不出现）；差异与"无法确认"措辞分开 |
| 浮层 | 从既有锚点展开/收回，符合 PMML；文字完整、默认展开有可读空间 |
| 报告 | 浏览器可打开、断网可看；概览/环境/逐对象/差异/原因/方法/建议齐备 |
| 语义 | L1/L2 口径正确；不可达与枚举失败一律 UNKNOWN，不算缺失、不算通过、不算修复成功 |
| 规模 | 大对象量报告可筛选/分页折叠；超大任务（十万级文件）内存有界 |
| 转义 | 中文、UNC 路径、含 `& < > " '` 的文件名不造成 HTML/脚本注入 |
| 取消 | 取消必须在可接受的时间内生效（目录内也检查取消，不只是目录之间），且不写出假的验证报告 |
| 可排障 | 验证动作写应用日志：开始（级别/任务/计划对象数）与结束（运行号/耗时/四态计数）可在 `app-*.log` 直接检索 |
| 零回归 | 迁移报告功能与按钮语义不变 |

## 6. 已知限制

- 报告只覆盖**本机**上该作业目录里的证据；跨机器查看需要完整复制作业目录。
- L2 抽样的覆盖率由作业选项决定，报告以实测抽样文件数据为准。
- 浮层是**应用内**浮层（不是独立 OS 窗口）：关闭浮层不等于取消验证。
- 验证取消的检查粒度是**每 4096 个目录条目**一次（`Verifier.CancelCheckInterval`）：这是吞吐与响应之间的折中，
  已验证"最坏延迟是毫秒级而非整个目录"，但不承诺逐条目即时中断。
